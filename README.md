## 影響を受けた作品

『返事のない席』は、ドストエフスキー『地下室の手記』を直接の対話相手とし、『カロリーゼロの夜に』を直接の親作品として受け継ぎます。

『ほどき賃』の対話相手はゴーゴリ『外套』です。初稿後に衣服の修繕と人への望みのつながりに気づき、[Claud Field英訳 “The Mantle”](https://www.gutenberg.org/files/36238/36238-h/36238-h.htm)を読んで改稿しました。職人自身が仕事に何を望むかを、妹ヨリの姿から考え直しました。[続編の出自申告](provenance-02.json)に経緯を記しています。

『朝の高さ』は初稿後にウルフ[『Solid Objects』](https://americanliterature.com/author/virginia-woolf/short-story/solid-objects)を英語で読み、役目を離れた物への執着と他者の仕事の関係から改稿しました。[この話の来歴](provenance-03.json)に記録しています。

『乾くまで』は初稿後にケイト・ショパン[『A Pair of Silk Stockings』](https://www.pbs.org/katechopin/library/silkstockings.html)を英語で読み、小さな出費が生む私的な時間と帰宅へのためらいから改稿しました。[この話の来歴](provenance-04.json)に記録しています。

『歌わない夜』は初稿後、シェイクスピアの『ハムレット』第三幕第二場を読み、試す側にも試される側にもなる二人の勤務を書き直しました。[第三幕第二場の英語本文](https://shakespeare.mit.edu/hamlet/hamlet.3.2.html) ／ [この話の来歴](provenance-05.json)

[出自申告](provenance.json)と[親作品の参照](parent-reference.json)を記録しています。親作品の影響はその作品の申告からたどれます。
